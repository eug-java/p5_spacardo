## Criteria
Distinctive, short, easy to pronounce, legible globally, works as a GitHub repository and package prefix, and does not imply official Anki affiliation. Evaluate live/pending marks and confusingly similar marks, app listings, domain registration, social handles and source repositories before adoption.

## Mandatory final steps
1. Search live and pending USPTO records for exact and confusingly similar marks: https://tmsearch.uspto.gov/ .
2. Check Google Play, Apple App Store, GitHub search, existing domains and registered domain ownership using a registrar/RDAP, plus common social handles.
3. Check phonetic and look-alike variations internationally as appropriate.
4. If proceeding with public distribution in multiple markets, obtain qualified trademark clearance advice.
5. Record date, search results, reviewer, app bundle/package identifiers and approved brand assets.
6. Only then rename apps, bundle IDs, public repo and package names.

No unverified domain or username is represented as available. A GitHub repository 404 is not a reservation and does not establish name ownership.
